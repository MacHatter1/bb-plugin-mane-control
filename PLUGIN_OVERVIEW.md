## What you get

A horse button sits beside the thread composer so you can switch Ponytail without typing a slash command. Open the menu, pick Off, Lite, Full, or Ultra, and the matching `/ponytail` command goes into the thread straight away. The button shows the mode you last picked for that thread, and its icon changes with it.

Mode-command messages in the transcript render as compact `Ponytail · Mode` status pills, with the real command still available underneath.

Mane Control does not read Ponytail's state. If you type `/ponytail` yourself, the message still becomes a pill, but the button keeps showing the last mode it set.

## Requirements

[Ponytail](https://github.com/DietrichGebert/ponytail) must be installed and available for the thread's provider. Mane Control accepts the Ponytail plugin skill, a user skill, or a registry install such as skills.sh. When Ponytail is missing, the control stays disabled and mode changes are blocked.
